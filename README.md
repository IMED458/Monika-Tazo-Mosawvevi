# მონიკა & თაზო — ქორწილის ციფრული მოსაწვევი

ბათუმი · 11 ოქტომბერი 2026

ერთფაილიანი სტატიკური გვერდი — გახსნის ანიმაცია, ბათუმის ცოცხალი პეიზაჟი,
დღიდან ღამემდე გადასვლა სქროლვისას, გალერეა, განრიგი, ლოკაცია და RSVP.

## სტრუქტურა

```
index.html              მთელი გვერდი (HTML + CSS + JS)
assets/photos/1..5.jpg  წყვილის ფოტოები
assets/batumi/          ბათუმის ნახატისებრი ილუსტრაციები
assets/audio/tango.mp3  ფონური მუსიკა
assets/og.jpg           ლინკის preview (Messenger/Instagram)
```

## რა სად შევცვალო

| რა | სად |
|---|---|
| ტექსტები | `index.html`-ში პირდაპირ, თითოეულ `<section>`-ში |
| თარიღი (countdown) | `index.html` → `var TARGET = new Date("2026-10-11T17:00:00+04:00")` |
| დღე/ღამის ფერები | `index.html` → JS-ში `DAY` და `NIGHT` ობიექტები |
| როდის ღამდება | `nightProgress()` → `scrollable * 0.74` (რაც უფრო დიდია, მით გვიან) |
| ფოტოები | `assets/photos/` — იგივე სახელებით ჩაანაცვლე |

RSVP პასუხი ამჟამად ინახება სტუმრის ბრაუზერში (`localStorage`).
რეალურ სერვერზე გასაგზავნად — `rsvpForm` submit-ში ერთი `fetch()` საკმარისია.
